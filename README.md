# White-Bot-Index

Index for **White Bot**.

## About

**White-Bot-Index** is the macro index for **White Bot**.

It provides a centralized list of available macros and their metadata so **White Bot** can find and load macros easily.

## Features

* Macro index
* Macro metadata
* Download links
* Version information
* Author information
* GitHub / Gist support
