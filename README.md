# Dll-Bot-Index

Index for Dll Bot.

## About

**Dll-Bot-Index** is the macro index for Dll Bot.

It provides a centralized list of available macros and their metadata so Dll Bot can find and load macros easily.

## Features

* Macro index
* Macro metadata
* Download links
* Version information
* Author information
* GitHub / Gist support
